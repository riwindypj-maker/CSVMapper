# 性能・プラットフォームテスト仕様

## この文書の責務

この文書は、性能上限、応答時間、Windows/macOS互換性、セキュリティ、ログの受入試験を定義する。

## この文書で扱う正本範囲

非機能要件の測定方法、期待結果、回帰観点。

## 参照する正本

- `docs/non-functional.md`
- `docs/specs/features/csv-export.md`

性能値、対応環境、セキュリティ、ログ要件は参照する正本に従う。本書では測定シナリオ、記録項目、合否判定方法だけを定義する。

## テスト対象

完成したWindows版とmacOS版、変換エンジン、ワーカー、ログ。

## 対象範囲

最大CSV、最大ノード構成、プレビュー・出力時間、中止、応答性、両OS同一結果、ログの機密性。

## 対象外

Intel Mac、Linux、Web、スマートフォン。

## テスト観点

- 基準端末での再現可能な測定
- 独立したCSV上限と、同時利用するノード上限の区別
- UI応答性とメモリ使用
- OS差異
- 外部通信と機密データの不存在

## 正常系

| ケース | 条件 | 合格条件 |
|---|---|---|
| PERF-001A | 100MB・100万行未満・10列のCSV | `NFR-PERF-001` と `NFR-PERF-006` を満たす |
| PERF-001B | 100万行・100MB以下・10列のCSV | `NFR-PERF-002` と `NFR-PERF-006` を満たす |
| PERF-001C | 500列・100MB以下・100万行以下のCSV | `NFR-PERF-003` と `NFR-PERF-006` を満たす |
| PERF-002 | 非機能要件で定義した2,000ノードと500列・1,000行のCSV | 最大ノード構成の合格条件を満たす |
| PERF-003 | 基準CSVの先頭100件 | `NFR-PERF-012` を満たす |
| PERF-004 | 100MB・10列・直接マッピング | `NFR-PERF-013` を満たす |
| PERF-005 | 最大ノード構成、10回のウォームアップ後に移動と接続を各100回 | `NFR-PERF-014` を満たす |
| PERF-006 | 出力とプレビューをそれぞれ10回中止 | 全試行で `NFR-PERF-015` を満たす |
| PERF-007 | `PERF-001A`〜`PERF-001C` と `PERF-002` の処理開始前から完了まで | 全ケースで `NFR-PERF-016` を満たす |
| PLATFORM-001 | Windows/macOSの共通フィクスチャ | `NFR-REL-005` を満たす |
| LOG-001 | 10MBを超えるログを6回生成 | 非機能要件のログ保持条件を満たす |

## 異常系

| ケース | 障害・観測方法 | 合格条件 |
|---|---|---|
| PERF-E001 | 長時間のプレビューと出力で進捗更新間隔と中止操作の受付表示を各100回測定する | 全試行で `NFR-PERF-008` を満たす |
| PERF-E002 | メモリ不足と書込失敗を個別に注入する | 値を含まないエラーを表示し、既存ファイルを維持する |
| SEC-E001 | 値・固定値・変換値・マッピング設定を識別可能なフィクスチャで処理する | ログとアプリケーション領域の検索結果が0件になる |
| SEC-E002 | ネットワーク通信を記録しながら主要機能を実行する | 外部サーバーまたはクラウド宛ての通信が0件になる |

## 回帰観点

- 編集ブロック数・文字列長増加時の測定結果を記録する。
- 表示倍率変更、ファイルシステム差、改行・文字コード差を両OSで確認する。
- バージョン固定後に再現可能なビルドを作成する。

## 実行方法

固定フィクスチャと計測手順を自動化し、基準端末で各ケースを実行する。処理時間、95パーセンタイル、ピークメモリを記録する。両OSのビルド、Linter、Formatter、単体・統合・E2Eを品質ゲートに含める。
