# プレビュー・検証テスト仕様

## この文書の責務

この文書は、手動プレビュー、問題分類、CSV出力可否のテスト期待値を定義する。

## この文書で扱う正本範囲

プレビューと検証の正常系、異常系、回帰観点。

## 参照する正本

- `docs/specs/features/preview-and-validation.md`
- `docs/specs/screens/main-screen.md`

問題分類と画面挙動は参照する正本に従う。本書ではプレビュー件数、グラフ状態、出力設定と観測点だけを定義する。

## テスト対象

検証エンジン、プレビュー評価、問題一覧、セル経路表示。

## 対象範囲

100・500・1,000件、出力列順、部分エラー、全体停止、手動更新、警告確認。

## 対象外

自動更新、待機時間、CSVファイル生成。

## テスト観点

- ボタン押下時点のスナップショット
- 出力と同一変換エンジン
- 列単位エラーと全体停止の境界
- 前回結果の未更新表示

## 正常系

| ケース | 条件・操作 | 観測点 |
|---|---|---|
| PREVIEW-001 | 初期値、500件、1,000件を順に選びボタンを押す | 押下ごとに選択件数以下の新しいスナップショットを表示する |
| PREVIEW-002 | 出力項目一覧とキャンバス位置を異なる順序にし、1項目を未接続にする | 一覧順で列を表示し、未接続列のセルを空文字にする |
| PREVIEW-003 | 2個の編集ブロックを通るセルを選択する | 元入力と各ブロック後の3段階を表示する |
| PREVIEW-004 | 1列だけに設定エラーを作る | 問題列を識別し、正常列の結果を維持する |
| PREVIEW-005 | 警告だけのグラフから問題一覧を開く | 対象ノードへ移動でき、出力操作を開始できる |
| PREVIEW-006 | プレビュー処理を10回中止する | すべて3秒以内に停止する |

## 異常系

| ケース | 条件・操作 | 観測点 |
|---|---|---|
| PREVIEW-E001 | CSV解析エラーまたは循環を含む内部状態 | 評価処理を開始せず、全体エラーを表示する |
| PREVIEW-E002 | 正本でエラーとなるマッピング | CSV出力操作を無効化する |
| PREVIEW-E003 | 絵文字を含む値をプレビューする | 出力文字コード固有の表現不能エラーを表示しない |
| PREVIEW-E004 | 件数選択UIを操作する | 100、500、1,000件以外を選択できない |

## 回帰観点

- マッピング変更だけでは評価回数が増えないことを確認する。
- 変更後は前回結果に未更新表示が付き、次のボタン押下後だけ外れることを確認する。
- プレビュー前後で出力先フォルダのファイル一覧が変化しないことを確認する。

## 実行方法

検証単体テスト、プレビュー統合テスト、UIコンポーネントテストを実行する。
