# 変換グラフテスト仕様

## この文書の責務

この文書は、ノード、端子、接続、循環判定、評価順、Undo・Redoのテスト期待値を定義する。

## この文書で扱う正本範囲

変換グラフの正常系、異常系、状態遷移、回帰観点。

## 参照する正本

- `docs/specs/domain/transformation-graph.md`
- `docs/specs/features/mapping-editor.md`

接続可否、問題分類、評価順、Undo・Redo 対象は参照する正本に従う。本書では構成するグラフと観測する状態だけを定義する。

## テスト対象

グラフモデル、接続検証、評価順、編集コマンドと履歴。

## 対象範囲

許可・禁止接続、分岐、結合入力、削除、循環、出力順、Undo・Redo。

## 対象外

文字列処理結果とCSV形式。

## テスト観点

- 有向非巡回という不変条件
- ノード種別と端子方向
- 入力数制限と分岐
- 接続順と結合順の分離
- 複合操作の履歴整合性

## 正常系

| ケース | 構成・操作 | 期待結果 |
|---|---|---|
| GRAPH-001 | 入力→出力、入力→ブロック→出力、ブロック→ブロックをそれぞれ作る | 接続後も有向非巡回で、出力値がトポロジカル順の評価結果と一致する |
| GRAPH-002 | 1入力を2出力へ分岐する | 両経路を同じ入力値から独立して評価する |
| GRAPH-003 | 同じ接続元を含む100入力を結合し、プロパティ順を入れ替える | 接続時刻ではなく変更後のプロパティ順で結合する |
| GRAPH-004 | 接続済みノードを削除する | 関連する辺だけを削除し、入力項目一覧を維持する |
| GRAPH-005 | キャンバス位置と異なる順序へ出力項目一覧を並べる | 一覧順と出力列順が一致する |
| GRAPH-006 | ノード追加、複数移動、自動整列を順に実行してUndo・Redoする | 操作単位で直前・直後の状態を復元する |

## 異常系

| ケース | 構成・操作 | 期待結果 |
|---|---|---|
| GRAPH-E001 | 正本の禁止接続を1種類ずつ試行する | 辺を追加せず、禁止理由を返す |
| GRAPH-E002 | 結合入力を0件、1件、101件にする | 0件はエラー、1件は警告、101件目は接続拒否になる |
| GRAPH-E003 | 出力項目0件、名称未入力、必須設定不足をそれぞれ作る | 対応する要素をエラーとして識別する |
| GRAPH-E004 | 入力要件を満たさず、出力にも到達しない編集ブロックを作る | エラーだけを表示し、未使用警告を重ねない |
| GRAPH-E005 | 入力CSVを変更してからUndo・Redoする | 変更前の履歴を実行できない |

## 回帰観点

- 分岐と合流を含む大規模DAGを `GRAPH-001` へ追加する。
- ノード削除後に孤立接続が残らないことを `GRAPH-004` で確認する。
- 自動整列・複数移動の履歴と、初期化後に履歴が破棄されることを確認する。
- ズーム、スクロール、選択、プレビュー状態が履歴へ入らないことを `GRAPH-006` で確認する。

## 実行方法

グラフモデルの単体テスト、状態管理の統合テスト、主要操作のコンポーネントテストを実行する。
