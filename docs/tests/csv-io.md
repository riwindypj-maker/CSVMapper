# CSV入出力テスト仕様

## この文書の責務

この文書は、CSV読込、CSV形式、安全な出力のテスト観点と期待結果を定義する。

## この文書で扱う正本範囲

CSV入出力の正常系、異常系、回帰観点、実行方法、期待結果。

## 参照する正本

- `docs/specs/domain/csv-format.md`
- `docs/specs/features/csv-import.md`
- `docs/specs/features/csv-export.md`
- `docs/non-functional.md`

CSV の解釈、出力表現、安全な出力手順は参照する正本に従う。本書では固定フィクスチャ、障害注入、観測点だけを定義する。

## テスト対象

CSVパーサー、文字コード判定、ストリーム入出力、ファイル同一性判定、安全な置換。

## 対象範囲

UTF-8、UTF-8 BOM 付き、Windows-31J、引用、エスケープ、項目内改行、空値、同一ファイル、失敗・中止。

## 対象外

TSV、Excel、複数CSV。

## テスト観点

- 文字列の忠実性と先頭ゼロ
- レコード・物理行の解析
- 文字コード判定と再指定
- 出力列順、引用、改行統一
- 入力・既存出力ファイルの保護
- OSごとのパスとファイル識別子

## 正常系

| ケース | 入力・操作 | 観測点 |
|---|---|---|
| CSV-001 | 引用、コンマ、引用符、項目内改行、空値を含む固定CSV | 解析後の論理レコードと各文字列がフィクスチャの期待値に一致する |
| CSV-002 | `氏名,氏名` のヘッダー | 元文字列を維持し、列番号付き表示名が一意になる |
| CSV-003 | BOM付きUTF-8、BOMなしUTF-8、Windows-31J、ASCIIの各バイト列 | 判定結果が正本の分岐と一致する |
| CSV-004 | ヘッダーだけのCSV | 解析成功と警告の両方を観測する |
| CSV-005 | コンマ、引用符、項目内改行、空文字を含む論理値 | 選択した文字コードと改行ごとの期待バイト列に一致する |
| CSV-006 | 3入力データレコード | ヘッダー1件と出力データレコード3件を生成する |
| CSV-007 | 既存出力ファイルを指定して出力を完了する | 一時ファイル完成前は既存内容を維持し、確定後だけ新しい内容へ置換する |

## 異常系

| ケース | 入力・障害 | 観測点 |
|---|---|---|
| CSV-E001 | 正本で解析エラーとする各固定CSV | 対象レコード番号を含む解析エラーになり、セッションへ反映しない |
| CSV-E002 | 絵文字を含む値をUTF-8とWindows-31Jでそれぞれ出力する | UTF-8は成功し、Windows-31Jは表現不能エラーになる |
| CSV-E003 | 入力と同じ正規化パス、シンボリックリンク、ハードリンクを出力先にする | 取得可能な識別情報に基づき同一実体を拒否する |
| CSV-E004 | 一時書込、容量不足、ファイル確定へ個別に失敗を注入する | 既存内容を維持し、一時ファイルを削除する |
| CSV-E005 | 出力処理を中止する | `NFR-PERF-015` を満たし、既存内容を維持して一時ファイルを削除する |
| CSV-E006 | 数式候補を出力ヘッダーと1,001行目だけに含めて1,000件プレビュー後に出力する | 全データ変換後かつファイル確定前に、内容を含めず検出件数を確認する |

## 回帰観点

- CRLF/LFと項目内改行の組合せを `CSV-001` と `CSV-005` へ含める。
- 空文字、ダブルクォーテーションだけの値、非常に長い値を `CSV-001` へ含める。
- Windowsの大文字小文字差、macOSのパス正規化、シンボリックリンク、ハードリンクを `CSV-E003` へ含める。
- 上書き取消、警告確認の取消、置換直前の失敗で既存内容を維持することを確認する。
- 異常終了後に残った一時ファイルを次回起動時に探索しないことを確認する。

## 実行方法

共通フィクスチャによる単体テスト、テンポラリディレクトリを使う結合テスト、Windows/macOS実ファイルテストを実行する。
