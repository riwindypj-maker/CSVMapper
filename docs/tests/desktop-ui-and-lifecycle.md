# デスクトップUI・ライフサイクルテスト仕様

## この文書の責務

この文書は、メイン画面、出力関連画面、キーボード操作、作業状態の破棄に関するテスト期待値を定義する。

## この文書で扱う正本範囲

GUI操作、画面状態、アクセシビリティ、初期化・終了の正常系、異常系、回帰観点。

## 参照する正本

- `docs/specs/screens/main-screen.md`
- `docs/specs/screens/output-workflow.md`
- `docs/specs/states/application-session.md`
- `docs/specs/design/ui-conventions.md`

画面状態、操作可否、破棄規則は参照する正本に従う。本書では操作経路と観測するUI・セッション状態だけを定義する。

## テスト対象

画面コンポーネント、キャンバス操作、ダイアログ、セッション状態管理。

## 対象範囲

配置、接続、検索、複数選択、ズーム、Undo・Redo、問題移動、出力設定、破棄確認、アクセシビリティ。

## 対象外

最終的なブランド表現とOS標準ダイアログ内部。

## テスト観点

- 操作可否とセッション状態の一致
- 大量ノードでの発見・操作
- 色に依存しない問題表現
- キーボードとフォーカス順
- 破壊的操作の確認

## 正常系

| ケース | 操作 | 観測点 |
|---|---|---|
| UI-001 | 入力配置、ノード移動・接続・削除、検索、複数選択、自動整列、ズーム、全体表示を順に行う | 各操作後のキャンバス状態とグラフ状態が一致する |
| UI-002 | プロパティと出力項目を編集してUndo・Redoする | 正本で履歴対象とした変更だけが復元される |
| UI-003 | エラー、警告、正常、選択、フォーカス、未更新の各状態を作る | 色を無効化しても文字、形状、アイコンで区別できる |
| UI-004 | マウスを使わず主要操作を実行する | 各操作を完了でき、フォーカスが画面の読み順と作業順に移動する |
| UI-005 | 出力設定、上書き確認、データ依存警告、進捗、中止、結果、フォルダ表示を順に操作する | セッション状態と利用可能な操作が一致する |
| LIFE-001 | 読込を中断する | 未読込へ戻り、解析途中の結果をセッションへ反映しない |
| LIFE-002 | CSV読込後に出力設定を開いて取り消す | 編集可能へ戻り、マッピングを維持する |
| LIFE-003 | 入力変更、初期化、終了をそれぞれ確定する | 正本で指定した作業状態を破棄する |
| LIFE-004 | 未読込、読込中、編集可能、プレビュー中、出力設定中、出力中、出力確認中、出力完了、出力失敗から終了する | 正本の遷移先へ移り、処理中の場合は停止と、存在する一時ファイルの削除を先に完了する |

## 異常系

| ケース | 操作 | 観測点 |
|---|---|---|
| UI-E001 | 未読込時に編集・プレビュー・出力を試みる | 操作を開始できない |
| UI-E002 | 読込中・出力中・出力確認中に編集を試みる | 作業状態を変更できない |
| LIFE-E001 | 入力変更または初期化の確認を取り消す | 確認前の作業状態をすべて維持する |
| LIFE-E002 | 編集可能、プレビュー中、出力設定中、出力中、出力確認中、出力完了、出力失敗から終了確認へ進み、取り消す | 入力 CSV、マッピング、出力項目、履歴、プレビューを維持し、中止・破棄済みの処理、出力設定、一時ファイルは復元しない |
| LIFE-E003 | 作業後にアプリケーションを再起動する | 前回のマッピングを復元しない |

## 回帰観点

- OS表示倍率を変更して `UI-001` と `UI-004` を再実行する。
- 最大構成でノード検索、選択、接続を実行する。
- 各ダイアログを閉じた後、呼出元へフォーカスが戻ることを確認する。
- 入力変更または初期化後に古い履歴・プレビューが残らないことを確認する。

## 実行方法

状態管理単体テスト、コンポーネントテスト、Windows/macOSのE2Eおよび目視確認を実行する。
