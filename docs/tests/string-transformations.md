# 文字列変換テスト仕様

## この文書の責務

この文書は、15種類の編集ブロックと文字境界のテスト期待値を定義する。

## この文書で扱う正本範囲

文字列変換の正常系、異常系、境界値、回帰観点。

## 参照する正本

- `docs/specs/domain/string-transformations.md`

変換規則と設定エラーの分類は参照する正本に従う。本書では具体的な入力、設定、観測する結果だけを定義する。

## テスト対象

各編集ブロックの純粋な変換処理と設定検証。

## 対象範囲

空文字、Unicode書記素クラスタ、位置・長さ、置換、削除、空白、大小文字、固定文字、結合、固定値。

## 対象外

CSVエスケープ、画面配置、ファイル入出力。

## テスト観点

- 同一入力・設定の決定性
- Unicode書記素クラスタの保全
- 空文字と範囲外
- 大小文字を区別する一致
- 変換対象文字の限定

## 正常系

| ケース | 入力・設定 | 期待結果 |
|---|---|---|
| STR-001 | 15種類の編集ブロックに代表値と空文字を与える | 正本の各 `BLK-*` に対応する結果と一致する |
| STR-002 | `A👨‍👩‍👧‍👦B` の2文字目を1文字抽出する | `👨‍👩‍👧‍👦` |
| STR-003 | `A👨‍👩‍👧‍👦B` の2文字目を1文字削除する | `AB` |
| STR-004 | `abc` の5文字目から2文字を削除・抽出する | 削除は `abc`、抽出は空文字 |
| STR-005 | `aaaa` の `aa` を `b` へ置換する | `bb` |
| STR-006 | 半角空白、全角空白、タブ、改行、ノーブレークスペースを含む値 | 各空白ブロックが正本で定めた文字だけを削除する |
| STR-007 | `aZé1` を大文字化し、`AzÉ1` を小文字化する | `AZé1`、`azÉ1` |
| STR-008 | `A`、空文字、`B` を区切り `,` で結合する | 空文字除外時は `A,B`、除外しない場合は `A,,B` |
| STR-009 | 固定値を未入力にする | 空文字 |

## 異常系

| ケース | 入力・設定 | 期待結果 |
|---|---|---|
| STR-E001 | 位置または文字数に `0`、`-1`、`1.5`、`abc` を設定する | 各値を設定エラーとして拒否する |
| STR-E002 | 置換前文字列または削除対象を空にする | 設定エラーとして拒否する |
| STR-E003 | 結合入力を0件にする | 入力不足エラーにする |

## 回帰観点

- 空文字、1文字、非常に長い文字列を `STR-001` のデータセットへ含める。
- 空、改行、引用符の区切り文字を `STR-008` へ追加する。
- 結合値の先頭・中間・末尾に空文字を置いたケースを `STR-008` へ追加する。
- ASCII以外の大小文字を `STR-007` へ追加する。

## 実行方法

テーブル駆動単体テストと、Unicode境界を生成するプロパティベーステストを実行する。
