# アプリケーションセッション状態仕様

## この文書の責務

この文書は、起動、CSV読込、編集、プレビュー、出力、初期化、終了に伴う状態とライフサイクルを定義する。

## この文書で扱う正本範囲

作業セッションと出力処理の状態、状態遷移、確認、破棄規則。

## 参照する正本

- CSV読込: `docs/specs/features/csv-import.md`
- マッピング編集: `docs/specs/features/mapping-editor.md`
- プレビュー: `docs/specs/features/preview-and-validation.md`
- CSV出力: `docs/specs/features/csv-export.md`

## 対象

アプリケーション実行中の作業セッションと CSV 出力処理。

## 対象範囲

起動から終了までのメモリ上の状態と利用者操作による遷移。

## 対象外

セッションの保存・復元、異常終了からの作業復旧、一時ファイル回収。

## 状態一覧

| 状態 | 説明 | 主な操作可否 |
|---|---|---|
| 未読込 | 入力 CSV がない | CSV選択可、編集・プレビュー・出力不可 |
| 読込中 | CSV を解析中 | 中断を除く編集・出力不可 |
| 編集可能 | CSV 読込済み | マッピング編集、検証、手動プレビュー可 |
| プレビュー中 | 指定件数を評価中 | 結果確定まで処理中表示、中止可 |
| 出力設定中 | 出力条件を入力中 | 設定確定または取消可 |
| 出力中 | 全データを変換中 | 中止可、マッピング編集不可 |
| 出力確認中 | 一時ファイル生成後にデータ依存の警告を確認中 | 続行または取消可、マッピング編集不可 |
| 出力完了 | CSV 出力成功 | 結果確認、フォルダ表示、編集再開可 |
| 出力失敗 | CSV 出力失敗または中止 | エラー確認、編集・再出力可 |
| 終了確認中 | 作業内容の破棄確認中 | 終了確定または取消可 |

## 状態遷移

| 現在 | 操作・結果 | 次 |
|---|---|---|
| 未読込 | CSV選択 | 読込中 |
| 読込中 | 解析成功 | 編集可能 |
| 読込中 | 解析失敗 | 未読込 |
| 読込中 | 中断 | 未読込 |
| 編集可能 | プレビューボタン押下 | プレビュー中 |
| プレビュー中 | 成功または列単位エラー | 編集可能 |
| プレビュー中 | 中止 | 編集可能 |
| 編集可能 | 出力開始 | 出力設定中 |
| 出力設定中 | 設定確定・検証成功・処理開始前警告なし、または確認済み | 出力中 |
| 出力設定中 | 設定検証失敗 | 出力設定中 |
| 出力設定中 | 処理開始前警告の確認を取消 | 出力設定中 |
| 出力設定中 | 取消 | 編集可能 |
| 出力中 | 警告なしで一時ファイル生成・確定成功 | 出力完了 |
| 出力中 | データ依存の警告を検出して一時ファイル生成成功 | 出力確認中 |
| 出力中 | 失敗または中止 | 出力失敗 |
| 出力確認中 | 続行・ファイル確定成功 | 出力完了 |
| 出力確認中 | 取消またはファイル確定失敗 | 出力失敗 |
| 出力完了・出力失敗 | ダイアログを閉じる | 編集可能 |
| 編集可能 | 入力変更を確定 | 読込中 |
| 編集可能 | 初期化を確定 | 未読込 |
| 未読込 | 終了 | 終了 |
| 読込中 | 終了 | 読込を中止して終了 |
| 編集可能・出力完了・出力失敗 | 終了 | 終了確認中 |
| 出力設定中 | 終了 | 出力設定を破棄して終了確認中 |
| プレビュー中・出力中・出力確認中 | 終了 | 処理を中止し、存在する一時ファイルを削除して終了確認中 |
| 終了確認中 | 終了確定 | 終了 |
| 終了確認中 | 取消 | 編集可能 |

入力変更または初期化の確認を取り消した場合は編集可能へ戻り、作業状態を変更しない。終了確認を取り消した場合も入力 CSV、マッピング、出力項目、履歴、プレビューを維持して編集可能へ戻るが、終了要求時に中止・破棄した処理、出力設定、一時ファイルは復元しない。処理中の終了要求では処理停止と、存在する一時ファイルの削除を完了してから終了確認を表示する。

マッピング変更ではプレビューを自動更新しない。前回プレビューは、次回のプレビューボタン押下による結果確定まで過去の結果であることを識別できる状態にする。

## 権限

利用者区分はなく、すべての操作を現在の端末利用者が行う。

## ライフサイクル

- ノード、接続、出力項目、Undo・Redo、プレビュー結果はメモリ上だけに保持する。
- 入力 CSV 変更時は現在のマッピングと Undo・Redo 履歴を確認後に破棄する。
- 初期化時は入力 CSV、マッピング、出力項目、履歴、プレビューを確認後に破棄する。
- 作業内容がある状態で終了する場合は確認し、確定後にすべての作業状態を破棄する。
- 再起動時に前回の作業状態を復元しない。
