# マッピングキャンバス基本設計案

## この文書の責務

この文書は、マッピングキャンバスのレイアウト、描画構成、座標系、仮想化、操作時の表示、キーボード操作、アクセシビリティの基本設計案を定義する。

## ステータス

技術検証用の設計案であり、両 OS のキャンバス検証完了までは確定基本設計として扱わない。順序 1 のプロトタイプには使用できるが、順序 2 以降の製品実装には使用しない。

## この文書で扱う正本範囲

キャンバスのコンポーネント構成、状態ごとの見た目、描画更新方法、ショートカット、性能を守る表示制約。

## 対象範囲

ノード、端子、接続線、選択矩形、ズーム、スクロール、複数選択、自動整列、検索・問題移動、キーボード操作。

## 対象外

グラフの接続可否、変換結果、プロパティ入力項目、最終的なブランドカラー。

## レイアウト

- 中央キャンバスは残り領域を占有し、最小表示幅を 480 logical pixel とする。
- 左領域は初期幅 280、右領域は初期幅 320、下部プレビューは初期高さ 240 logical pixel とし、利用者がサイズ変更できる。
- キャンバスは配置済みノードの外接矩形に 400 logical pixel の余白を加えた作業範囲を持つ。
- ズーム範囲は 25% から 200%、初期値は 100% とする。
- 「全体表示」は配置済みノードの外接矩形が表示領域へ収まる倍率と中心位置を計算する。

## コンポーネント

- `CanvasViewport`: クリップ、ポインター入力、パン、ズーム、表示範囲計算を担当する。
- `EdgeLayer`: 1 個の `Svg` 内で表示対象の接続線を描画する。
- `NodeLayer`: 表示対象ノードを React Native `View` として絶対配置する。
- `NodeView`: 種別、名称、問題状態、選択、フォーカス、端子を表示する。
- `PortView`: 入出力方向、接続可否、ポインターのドラッグ接続とキーボード接続操作を提供する。
- `SelectionOverlay`: 選択矩形、接続ドラッグ、一時ガイドを描画する。

ノードと端子はアクセシブルな React Native コンポーネントとし、接続線だけを SVG で描画する。Skia と Reanimated は両 OS の互換性検証が完了するまで必須依存にしない。

## 座標と描画

- モデルはズームに依存しないワールド座標を保持する。
- 画面座標は `screen = world * zoom + pan` で算出する。
- ノード位置は整数 logical pixel で確定し、描画時だけ浮動小数を許可する。
- 接続線は端子中心を始終点とする三次ベジェ曲線で描画する。
- パンとズームではモデル座標を書き換えない。
- ドラッグ中は選択ノードの一時座標だけを更新し、終了時に 1 件の移動コマンドとして確定する。
- 1 フレーム中の複数ポインターイベントは `requestAnimationFrame` 単位にまとめる。

## ポインターによる端子接続

- 出力端子をドラッグし、入力端子上で離すと接続を作成する。
- ドラッグ中は接続元出力端子からポインタ位置までの仮線を直線で表示する。
- 入力端子以外で離した場合、または `Escape` では接続をキャンセルする。
- 不正な接続先へドロップした場合は理由を示し、下書き接続もクリアする。
- キーボード接続は次節のとおり段階確定とし、ドラッグを必須にしない。

## 仮想化

- 表示領域に 300 logical pixel の overscan を加えた矩形と交差するノードだけを描画する。
- ノード位置は 512 logical pixel 単位の固定グリッドへ索引し、表示対象の探索を全件走査に依存させない。
- 接続線は両端のどちらかが表示対象、または線の外接矩形が表示範囲と交差する場合だけ描画する。
- 選択中、ドラッグ中、キーボードフォーカス中のノードは overscan 外でも操作終了まで保持する。
- 検索または問題移動は対象ノードを先に表示中心へ移動し、その後フォーカスする。
- プレビュー表は行と列を仮想化し、500 列×1,000 行のセルを同時にマウントしない。

## 状態更新

- NodeView はノード ID 単位でストアを購読する。
- 接続線は接続 ID と両端座標の変更だけで更新する。
- 選択集合、viewport、一時ドラッグ座標はグラフ本体と別の一時 UI 状態に置く。
- 接続開始時に禁止先を算出し、端子の外観と操作可否を同時に更新する。
- 自動整列は画面操作と分離したジョブとして座標案を計算し、利用者が実行した 1 操作として全座標を確定する。JavaScript 上で要件を満たさない場合は Processing Core 側へ移す。

## 表示状態

- 入力、編集、出力ノードは文字ラベルと形状で区別する。
- エラー、警告、選択、キーボードフォーカスは互いに上書きせず併記する。
- 接続可能端子は操作開始時に強調し、接続不可端子は無効な外観とアクセシビリティ状態を持つ。
- 表示範囲外に問題がある場合は問題件数をツールバーへ表示し、問題一覧から移動できるようにする。
- プレビュー未更新はキャンバスではなくプレビュー領域の見出しと状態表示で示す。

## キーボード操作

| 操作               | Windows                        | macOS                       |
| ------------------ | ------------------------------ | --------------------------- |
| Undo               | `Ctrl+Z`                       | `Command+Z`                 |
| Redo               | `Ctrl+Y` または `Ctrl+Shift+Z` | `Command+Shift+Z`           |
| 全選択             | `Ctrl+A`                       | `Command+A`                 |
| 検索へ移動         | `Ctrl+F`                       | `Command+F`                 |
| 選択削除           | `Delete`                       | `Delete` または `Backspace` |
| ズームイン・アウト | `Ctrl++` / `Ctrl+-`            | `Command++` / `Command+-`   |
| 全体表示           | `Ctrl+0`                       | `Command+0`                 |

- `Tab` はツールバー、素材領域、キャンバス、出力・プロパティ領域、プレビューの順に移動する。
- キャンバス内では矢印キーで近接ノードへ移動し、`Enter` でノードまたは端子を操作対象にする。
- キーボード接続は「接続元端子を確定し、接続先端子を選び、確定する」の順で行い、ドラッグを必須にしない。
- `Escape` は接続中、選択矩形、ドラッグ中の一時操作を取り消す。

## アクセシビリティ

- ノードは種別、表示名、エラーまたは警告件数、接続数をアクセシブル名称または説明に含める。
- 端子は入出力方向、接続済み状態、接続可否を通知する。
- 接続線の選択・削除は線そのものだけに依存せず、両端ノードの接続一覧からも実行できる。
- フォーカス対象を仮想化で破棄しない。
- ズーム率を変更してもフォーカスリングを視認できる太さに保つ。

## 性能判定

2,000 ノード構成で、ノード移動と接続をそれぞれ 10 回ウォームアップ後に 100 回測定する。入力受付から次の画面反映までの 95 パーセンタイルが `NFR-PERF-014` を満たすことを採用条件とする。ノード数、接続数、描画中ノード数、描画中接続数、フレーム時間を記録する。
