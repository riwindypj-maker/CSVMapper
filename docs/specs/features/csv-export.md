# CSV出力機能仕様

## この文書の責務

この文書は、出力設定、出力前確認、CSV 生成、安全な置換、中止、結果表示を定義する。

## この文書で扱う正本範囲

CSV出力に関する利用者操作、処理、結果、エラー、ファイル保護。

## 参照する正本

- CSV形式: `docs/specs/domain/csv-format.md`
- 検証: `docs/specs/features/preview-and-validation.md`
- 出力画面: `docs/specs/screens/output-workflow.md`

## 対象機能

出力設定、全データ変換、安全なファイル確定、中止、処理結果表示。

## 対象範囲

出力先・ファイル名・文字コード・改行コード指定、全行変換、進捗、中止、安全な上書き、完了結果。

## 対象外

複数ファイル出力、出力履歴、異常終了後に残った一時ファイルの次回起動時検出・削除、既存ファイルの属性・権限の維持。

## 現行仕様

- 出力先フォルダと `.csv` ファイル名を指定できる。
- 初期ファイル名は `入力名_変換済み_YYYYMMDDHHmmss.csv` とする。
- 文字コードと改行コードは CSV 形式仕様の選択肢と初期値に従う。
- 出力項目名をヘッダーにし、出力項目一覧の順序で全フィールドを引用して出力する。
- 入力 1 データレコードにつき出力 1 データレコードを生成する。
- 出力中は進捗率または処理件数を表示し、利用者は処理を中止できる。
- 完了後に出力件数、出力先、処理時間を表示し、出力先フォルダを開ける。

## 安全な出力

1. 正規化絶対パスを比較し、OS API で取得できる場合はファイル識別子も比較する。
2. 入力 CSV と同一実体なら出力を禁止する。ファイル識別子を取得できなければパス比較結果を用いる。
3. 同名ファイルがあれば処理開始前に上書きを確認する。
4. 出力先と同じフォルダに、衝突を避けるアプリ固有名の一時ファイルを作る。
5. 出力ヘッダーと全データを変換して一時ファイルへ書き込みながら、選択した文字コードの表現可否と数式として解釈される可能性のあるヘッダーまたは値を検証する。
6. Windows-31J 選択時に表現不能な文字を検出した場合はエラーとして一時ファイルを削除する。
7. 数式として解釈される可能性のあるヘッダーまたは値を検出した場合は、内容を表示せず件数を示し、一時ファイルの確定前に続行を確認する。取り消した場合は一時ファイルを削除する。
8. 一時ファイルへの全出力が成功し、必要な確認で続行された後だけ対象ファイルへ置き換える。
9. 失敗または中止時は処理中の一時ファイルを削除し、既存ファイルを変更しない。

既存ファイルの属性と権限の維持は保証しない。異常終了により残った一時ファイルを次回起動時に探索・削除しない。

## 入力

検証済みの入力 CSV、変換グラフ、出力項目、出力設定、同名ファイルを含む処理開始前警告への利用者確認。

## 処理

CSV をストリーム処理し、各レコードを変換して一時ファイルへ書き込む。データ依存のエラーと警告は出力ヘッダーと全データを対象に判定する。数式として解釈される可能性のあるヘッダーと値は変更せず、全データの変換後かつ対象ファイルの確定前に続行を確認する。

## 出力

CSV ファイルと、件数・出力先・処理時間を含む処理結果。

## エラー

マッピングエラー、出力名不正、同一ファイル、権限不足、容量不足、使用中、Windows-31J 表現不能、書込・置換失敗を表示し、既存ファイルを保護する。

## 権限

認証はない。出力権限は OS のファイルシステム権限に従う。
