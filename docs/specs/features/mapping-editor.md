# マッピング編集機能仕様

## この文書の責務

この文書は、入力項目、編集ブロック、出力項目をキャンバス上で編集する利用者向け機能を定義する。

## この文書で扱う正本範囲

配置、移動、接続、削除、検索、整列、出力項目編集、Undo・Redo、初期化の振る舞い。

## 参照する正本

- 接続規則: `docs/specs/domain/transformation-graph.md`
- 文字列処理: `docs/specs/domain/string-transformations.md`
- 画面: `docs/specs/screens/main-screen.md`

## 対象機能

入力項目、編集ブロック、出力項目によるマッピングの作成と編集。

## 対象範囲

- 入力項目と編集ブロックのドラッグ配置
- 出力項目の追加、名称変更、削除、順序変更
- 端子間接続、接続線削除、循環防止
- 複数選択、移動、ズーム、スクロール、全体表示、自動整列
- プロパティ編集、Undo・Redo、入力 CSV を含むセッション全体の初期化

## 対象外

設定の保存・読込、画像出力、条件分岐、複数キャンバス。

## 現行仕様

- 入力項目一覧には全項目を残し、キャンバスには使用項目だけを 1 ノードずつ配置する。
- 編集ブロックをツールボックスから配置し、選択時にプロパティを表示・編集する。
- 出力項目を自由に追加・編集・削除し、一覧上の順序で出力列順を決める。
- 出力項目名は必須とする。同名は許可するが警告する。
- 端子方向、入力数、循環の規則に反する接続を作成できない。
- ノード削除時に関連する接続線も削除する。入力ノードを削除しても入力項目一覧は維持する。
- 選択要素を視覚的に識別し、複数選択・移動、自動整列を行える。
- 入力項目検索とエラー一覧から対象ノードへ移動できる。
- 初期化は入力 CSV を含むセッション全体を破棄する操作とし、実行前に確認する。

## Undo・Redo

対象はノード追加・移動・削除・接続、プロパティ変更、出力項目の追加・削除・名称・順序、複数移動、自動整列とする。ズーム、スクロール、選択、プレビュー表示、セッション全体を破棄する初期化は対象外とする。履歴は現在の実行中だけ保持し、入力 CSV の変更または初期化で破棄する。

## 入力

利用者のキャンバス操作、接続操作、プロパティ値、出力項目定義。

## 処理

各操作をグラフ仕様に照らして検証し、有効な変更だけをメモリ上の作業状態へ反映する。

## 出力

現在の変換グラフ、出力項目順、Undo・Redo 履歴、問題状態。

## エラー

不正接続、循環、必須設定不足、不正な数値設定は該当操作または項目の近くに理由を表示する。
