# CSV読込機能仕様

## この文書の責務

この文書は、入力 CSV の選択、文字コード指定、解析、入力項目一覧への反映を定義する。

## この文書で扱う正本範囲

CSV読込に関する利用者操作、処理、表示結果、エラー。

## 参照する正本

- CSV形式: `docs/specs/domain/csv-format.md`
- セッション状態: `docs/specs/states/application-session.md`
- 画面: `docs/specs/screens/main-screen.md`

## 対象機能

ファイル選択ダイアログから 1 件の `.csv` を読み込み、ヘッダーと概要を作業画面へ反映する機能。

## 対象範囲

ファイル選択、文字コード判定と再指定、ストリーム解析、入力項目一覧とファイル概要への反映。

## 対象外

複数ファイル、CSV の更新・移動・削除、保存済みマッピングの再適用。

## 現行仕様

- `.csv` 1 件を選択し、ファイル名、場所、サイズ、判定した文字コードを表示する。
- 読込中は進捗と中断操作を表示する。中断時は解析結果をセッションへ反映せず未読込へ戻る。
- ヘッダー、データ行、引用、項目内改行、項目数を CSV 形式仕様に従って解析する。
- 読み込んだデータ行数と項目数を表示する。
- ヘッダー全項目を元の列順で入力項目一覧へ表示する。
- 同名ヘッダーは列番号付き表示名で識別するが、元のヘッダー文字列は変更しない。
- 入力項目を名称で検索し、サンプル値を確認できる。
- 利用者は必要な項目だけをキャンバスへ配置できる。
- 文字コードを変更して再読込する場合と入力ファイルを変更する場合は、現在の作業内容が破棄されることを確認する。

## 入力

- 利用者が選択した `.csv` ファイル
- 自動判定または利用者が指定した文字コード

## 処理

CSV 全体を一括でメモリ展開せず、形式検証とヘッダー・データ概要の抽出を行う。同一ファイル判定用に正規化絶対パスを取得し、OS API で取得できる場合はファイル識別子も取得する。

## 出力

- ファイル概要、文字コード、データ行数、項目数
- 入力項目一覧とサンプル値
- 読込済みセッション状態

## エラー

CSV 以外、読込不能、空ファイル、ヘッダー不在、空ヘッダー、未閉じ引用符、項目数不一致、不明な文字コードをエラーとし、対象レコード番号と取得可能な物理行範囲を表示する。ヘッダーだけの場合は警告とする。

## 権限

認証および権限制御はない。ファイルの読込権限は OS のファイル選択結果に従う。
