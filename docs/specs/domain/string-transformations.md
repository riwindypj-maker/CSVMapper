# 文字列変換ドメイン仕様

## この文書の責務

この文書は、編集ブロックの入力、設定、処理結果、境界値を定義する。

## この文書で扱う正本範囲

15 種類の文字列編集処理、文字位置、空白、大小文字、結合、固定値の規則。

## 参照する正本

- グラフ: `docs/specs/domain/transformation-graph.md`
- プロジェクト範囲: `docs/requirements.md`

## 対象ドメイン

入力文字列から出力文字列への決定的な変換。

## 対象範囲

初期リリースで提供する15種類の編集ブロックと、その設定値・境界値。

## 対象外

正規表現、数値・日付計算、条件分岐、利用者定義スクリプト。

## 業務ルール

編集ブロックは 1 種類の文字列処理を担当し、設定された規則以外の暗黙変換を行わない。

### 編集ブロック

| ID | 名称 | 入力 | 設定と結果 |
|---|---|---:|---|
| BLK-001 | 前方文字削除 | 1 | 先頭から指定文字数を削除する |
| BLK-002 | 後方文字削除 | 1 | 末尾から指定文字数を削除する |
| BLK-003 | 指定位置文字削除 | 1 | 指定位置から指定文字数を削除する |
| BLK-004 | 部分文字列抽出 | 1 | 指定位置から指定文字数を抽出する |
| BLK-005 | 文字列置換 | 1 | 大小文字を区別し、一致するすべてを置換する |
| BLK-006 | 指定文字列削除 | 1 | 大小文字を区別し、左から重複しない一致をすべて削除する |
| BLK-007 | 前後空白削除 | 1 | 前後の半角空白、全角空白、タブを削除する |
| BLK-008 | 全空白削除 | 1 | 半角空白と全角空白をすべて削除する |
| BLK-009 | 大文字変換 | 1 | ASCII の `a-z` だけを大文字化する |
| BLK-010 | 小文字変換 | 1 | ASCII の `A-Z` だけを小文字化する |
| BLK-011 | 前方固定文字追加 | 1 | 入力値の前へ指定文字列を追加する |
| BLK-012 | 後方固定文字追加 | 1 | 入力値の後ろへ指定文字列を追加する |
| BLK-013 | 空文字置換 | 1 | 入力値が空文字の場合だけ指定文字列へ置換する |
| BLK-014 | 文字列結合 | 1〜100 | プロパティで定義した順に入力を結合する |
| BLK-015 | 固定値 | 0 | 指定文字列を出力する。未入力は空文字とする |

### 文字位置と文字数

- 先頭を 1 文字目とし、Unicode 書記素クラスタを 1 文字と数える。
- 結合文字、サロゲートペア、絵文字シーケンスを途中で分割しない。
- 位置と文字数は 1 以上の整数とし、0、負数、小数、非数値を設定エラーとする。
- 位置が文字列長を超える場合、削除は入力をそのまま返し、抽出は空文字を返す。
- 文字数が残りを超える場合は末尾までを対象とする。

### 置換・削除

- 文字列置換の置換前文字列は必須、置換後文字列は空文字を許可する。
- 指定文字列削除の対象文字列は必須とする。
- 空白削除では改行とノーブレークスペースなど対象外の Unicode 空白を削除しない。
- 大文字・小文字変換では日本語、数字、記号、ASCII 以外を変更しない。

### 文字列結合

- 区切り文字は任意文字列とし、空文字、改行、ダブルクォーテーションを許可する。
- 空文字除外を初期値として有効にし、利用者が無効へ変更できる。
- 区切り文字は空文字除外後に残った値の間だけへ挿入する。
- 空文字除外後に値が残らない場合は空文字を返す。
- 入力 0 件はエラー、1 件は警告とする。

## 計算ルール

各ブロックは入力文字列と設定から出力文字列を一度だけ決定し、暗黙の型変換を行わない。複数ブロックの結果は `docs/specs/domain/transformation-graph.md` の評価順に従って合成する。

## 判定条件

- 必須設定が不足したブロックと不正な位置・文字数を設定エラーとする。
- 固定値の未入力はエラーにせず空文字として扱う。
- 文字列結合の入力数に応じたエラーと警告は業務ルールに従う。

## 不変条件

- 入出力は常に文字列である。
- 同じ入力と設定から常に同じ結果を返す。
- ブロックは CSV エスケープや文字コード変換を行わない。
