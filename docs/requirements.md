## 目的

CSV の項目を GUI 上で視覚的にマッピングし、文字列編集処理を適用した CSV を、プログラミングなしで生成できるデスクトップアプリケーションを提供する。Windows と macOS で同じ操作性と変換結果を提供し、CSV データは外部へ送信せずローカル端末内で処理する。

## 利用者

CSV の入力項目と必要な出力項目を理解している一般業務ユーザーを対象とする。プログラミング、SQL、正規表現、データベース、コマンドラインの知識は求めない。

## 要件

- 入力 CSV のヘッダーを入力項目として表示し、必要な項目だけをキャンバスへ配置できる。
- 出力項目を任意に定義し、並び順を指定できる。
- 入力項目、編集ブロック、出力項目を有向の接続で構成できる。
- 入力値を直接出力するか、複数の文字列編集処理を接続順に適用できる。
- 現在のマッピングを検証し、利用者の操作で変換結果をプレビューできる。
- 1 件の入力 CSV を変換し、指定した形式の CSV を安全に出力できる。
- 設定は実行中だけ保持し、終了時に破棄する。

## 対象範囲

- CSV ファイル 1 件の読込と出力
- UTF-8、UTF-8 BOM 付き、Windows-31J の入出力
- 入力項目一覧、出力項目定義、GUI マッピングキャンバス
- 直接マッピングと 15 種類の文字列編集ブロック
- 接続検証、Undo・Redo、手動プレビュー
- 安全なファイル置換、進捗表示、中止、処理結果表示
- Windows 11 64 ビット
- macOS 14 以降の Apple Silicon 搭載 Mac

## 対象外

- 数値・日付計算、集計、並び替え、抽出、重複排除、条件分岐、正規表現、任意スクリプト
- 複数 CSV の結合または一括変換
- Excel、TSV、データベース、Web API、クラウドとの連携
- 認証、マッピング設定の保存・復元・テンプレート化、変換履歴
- Web、スマートフォン、Linux、Intel 搭載 Mac
- 自動アップデート、多言語対応
- 異常終了後に残った一時ファイルを次回起動時に検出または削除する機能

## 前提条件

- 入力値、編集結果、固定値、出力値はすべて文字列として扱い、先頭ゼロを保持する。
- CSV の 1 レコード目をヘッダー、2 レコード目以降をデータとして扱う。
- 1 入力データレコードから 1 出力データレコードを生成する。
- マッピング設定は処理の都度作成し、アプリケーション終了後に保持しない。
- CSV データは利用者が選択したファイル、出力先、処理中の一時ファイル以外へ保存しない。

## 制約

- React Native、React Native Windows、React Native macOS を利用する。
- Windows 版と macOS 版は同一の変換ロジックを利用する。
- 入力 CSV を変更、移動、削除しない。
- 入力 CSV と同一の実体ファイルへ出力しない。
- データベースおよび外部サービスを使用しない。
