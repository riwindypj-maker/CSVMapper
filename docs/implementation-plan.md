## 依存関係

| 対象             | 依存先                               | 理由                                                                 |
| ---------------- | ------------------------------------ | -------------------------------------------------------------------- |
| CSV 読込・出力   | CSV 形式ドメイン                     | 文字コード、CSV 構文、改行規則を共有するため                         |
| マッピング編集   | 変換グラフ                           | 接続可否と循環判定を画面から分離するため                             |
| プレビュー・出力 | 文字列変換、変換グラフ               | 同一の評価結果を利用するため                                         |
| UI               | 技術検証                             | キャンバスと両 OS の実現可能性を先に確認するため                     |
| 共通 UI          | Windows/macOS アプリケーションホスト | React Native 系 minor が異なる両ホストで同じソースを継続検証するため |
| プレビュー・出力 | Processing Core                      | 長時間処理と全データを UI スレッドから分離するため                   |
| 受入試験         | 全実装工程                           | 初期リリースの横断条件を確認するため                                 |

## テスト方針

CSV 解析、文字列境界、グラフ循環判定、安全な上書きは失敗時の影響が大きく期待値が明確なため、先行テストを基本とする。UI の配置や操作感はコンポーネントテストと両 OS の実機確認を組み合わせる。

| 観点        | リスク                 | 確認方法                             | 実施タイミング         |
| ----------- | ---------------------- | ------------------------------------ | ---------------------- |
| CSV 互換性  | データ誤解釈           | 単体・結合・実ファイルテスト         | 実装前から継続         |
| 変換結果    | データ破損             | 境界値・プロパティベース・回帰テスト | ドメイン実装前から継続 |
| 接続と Undo | 不正フロー・状態不整合 | 状態遷移・UI テスト                  | 編集機能ごと           |
| 安全な出力  | 既存ファイル破損       | 失敗注入を含む実ファイルテスト       | 出力実装前から継続     |
| 性能        | UI 停止・メモリ超過    | 基準端末の計測                       | 技術検証、統合、受入   |
| OS 差異     | 結果・操作の差         | Windows/macOS 共通フィクスチャ       | 各統合工程と受入       |

## 影響範囲

- 変更対象: 新規 React Native デスクトップアプリケーション、テスト、ビルド・配布設定
- 影響する既存機能: 既存実装なし

## 未決定事項

- Windows 候補の React Native `0.84.1`・React Native Windows `0.84.0` と、macOS 候補の React Native `0.81.6`・React Native macOS `0.81.9` を OS 別ホストで利用できること
- Windows ホストで React Native Windows の固定依存を解決し、共通 UI をビルドできること
- CMake が生成する Processing Core の静的ライブラリを Windows ホストの MSBuild からリンクできること
- react-native-svg `15.15.5`、@dagrejs/dagre `3.0.0`、ICU4C `78.3` の両 OS 実ビルド・性能・配布サイズ
- Windows の Store 利用有無、本番署名方式、macOS の DMG 生成手段

これらは順序 1 の技術検証で確定する。`docs/specs/design/application-architecture.md`、`docs/specs/design/mapping-canvas.md`、`docs/specs/modules/processing-core.md` の未決定事項が解消するまで、順序 2 の製品実装へ進まない。
