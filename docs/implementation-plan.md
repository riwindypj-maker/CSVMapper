## 実装順序・進捗

| 順序 | 対象 | ステータス | 完了内容 | 残作業 | 確認方法 |
|---|---|---|---|---|---|
| 1 | 技術検証と開発基盤 | 未着手 | なし | React Native 系バージョン、キャンバス、ファイル処理、ワーカー、配布方式を両 OS で検証する | 検証用ビルド、性能測定、技術選定レビュー |
| 2 | CSV形式・文字列変換ドメイン | 未着手 | なし | CSV、書記素クラスタ、15 ブロック、グラフ評価を実装する | 単体テスト、Linter、Formatter |
| 3 | CSV読込 | 未着手 | なし | 文字コード判定、ストリーム解析、入力項目生成を実装する | CSV読込テスト、大容量試験 |
| 4 | マッピング編集 | 未着手 | なし | ノード、接続、検索、複数選択、自動整列、Undo・Redoを実装する | ドメインテスト、コンポーネントテスト |
| 5 | 画面構成とアクセシビリティ | 未着手 | なし | メイン画面、プロパティ領域、キーボード操作、フォーカス順を実装する | 両 OS の目視・操作確認、アクセシビリティ確認 |
| 6 | 検証と手動プレビュー | 未着手 | なし | エラー・警告、手動プレビュー、セル経路表示を実装する | 検証テスト、UIテスト、性能試験 |
| 7 | CSV出力 | 未着手 | なし | 出力設定、全データのWindows-31J・数式候補検証、一時ファイル確定前の警告確認、安全な置換、中止、結果表示を実装する | 出力・異常系テスト、実ファイル確認 |
| 8 | セッションと終了処理 | 未着手 | なし | Undo対象外の初期化、入力変更、処理中を含む終了遷移、設定・履歴・一時ファイルの破棄を実装する | ライフサイクルテスト |
| 9 | 両OS受入と品質確認 | 未着手 | なし | 独立したCSV上限、2,000ノード構成、応答時間の95パーセンタイル、1GiBのピークメモリ増加上限を含む全受入条件、署名・配布、文書整合を確認する | 全テスト、Linter、Formatter、ビルド、実機確認 |

## 依存関係

| 対象 | 依存先 | 理由 |
|---|---|---|
| CSV読込・出力 | CSV形式ドメイン | 文字コード、CSV構文、改行規則を共有するため |
| マッピング編集 | 変換グラフ | 接続可否と循環判定を画面から分離するため |
| プレビュー・出力 | 文字列変換、変換グラフ | 同一の評価結果を利用するため |
| UI | 技術検証 | キャンバスと両 OS の実現可能性を先に確認するため |
| 受入試験 | 全実装工程 | 初期リリースの横断条件を確認するため |

## テスト方針

CSV解析、文字列境界、グラフ循環判定、安全な上書きは失敗時の影響が大きく期待値が明確なため、先行テストを基本とする。UIの配置や操作感はコンポーネントテストと両 OS の実機確認を組み合わせる。

| 観点 | リスク | 確認方法 | 実施タイミング |
|---|---|---|---|
| CSV互換性 | データ誤解釈 | 単体・結合・実ファイルテスト | 実装前から継続 |
| 変換結果 | データ破損 | 境界値・プロパティベース・回帰テスト | ドメイン実装前から継続 |
| 接続とUndo | 不正フロー・状態不整合 | 状態遷移・UIテスト | 編集機能ごと |
| 安全な出力 | 既存ファイル破損 | 失敗注入を含む実ファイルテスト | 出力実装前から継続 |
| 性能 | UI停止・メモリ超過 | 基準端末の計測 | 技術検証、統合、受入 |
| OS差異 | 結果・操作の差 | Windows/macOS共通フィクスチャ | 各統合工程と受入 |

## 影響範囲

- 変更対象: 新規 React Native デスクトップアプリケーション、テスト、ビルド・配布設定
- 影響する既存機能: 既存実装なし

## 未決定事項

- 採用する React Native、React Native Windows、React Native macOS と関連ライブラリの具体的バージョン
- Windows と macOS の配布、署名、インストーラー方式

これらは順序 1 の技術検証で確定し、確定前に基本設計へ進まない。
